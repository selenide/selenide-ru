Подарок на день рождения: поддержка Java 11

В подарок на день рождения Selenide 7.19.1 скомпилирована под Java 11.

Да-да, мы знаем. На дворе 2026 год. Но где-то ещё живут несчастные динозавры, которые гоняют тесты на Java 11. Это для вас, динозавры! 🦖

Но это разовый подарок: день рождения бывает не каждый день. Следующие версии снова будут требовать Java 17. Так что обновите уже джаву. Серьёзно.


Настройка Configuration.timezone

В Selenide 7.19.0 мы добавили метод clock().setTimezone(). Но он меняет часовой пояс только в текущей вкладке.

Теперь есть настройка, которая задаёт часовой пояс для всего браузера - всех вкладок, окон и воркеров:

Configuration.timezone = "America/New_York";
// либо -Dselenide.timezone=America/New_York

Как это работает:

  • Локальный Chrome, Edge или Firefox запускается с переменной окружения TZ (браузеры на Windows её игнорируют, поэтому на Windows Selenide просто пишет предупреждение в лог).
  • Удалённый браузер получает capability se:timeZone (поддерживается Selenium Grid в Docker).
  • Если вы используете capabilities selenoid:options или moon:options, в них тоже добавляется timeZone.
  • Принимаются только ID из tz database (вроде Europe/Tallinn). Неправильный часовой пояс сразу вызывает ошибку.

См. issue 3475 и PR 3476.


Опция --timezone в Selenide CLI и MCP

Та же настройка теперь доступна в Selenide CLI и Selenide MCP-сервере:

selenide open --timezone=Asia/Tokyo https://selenide.org

См. issue 3475 и PR 3476.


Selenide CLI skill: дампы HTML-страниц

В Selenide CLI skill теперь описаны дампы HTML-страниц. Теперь ваш AI-агент будет знать, что не стоит каждый раз делать скриншот и пытаться его анализировать как картинку. Вместо этого он должен сообразить, что дешевле анализировать “*.html” файл.

См. PR 3481.


Подчищаем память в SelenideLogger

Когда у потока удалялся последний листенер, SelenideLogger всё равно хранил для этого потока пустую запись. При большом количестве потоков такие записи могли накапливаться. Теперь запись потока удаляется вместе с его последним листенером.

Спасибо Matthias Kurz за PR 3463!
